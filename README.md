# 💎 Diamantina — Calculadora de Muestreo

App PWA para perforación diamantina. Funciona **sin internet** una vez instalada.

---

## 🚀 Cómo instalar en 10 minutos (GRATIS)

### Paso 1 — Crear cuenta en GitHub
1. Ve a https://github.com
2. Clic en **Sign up** → crea cuenta gratis

### Paso 2 — Subir el proyecto
1. En GitHub clic en **+** → **New repository**
2. Nombre: `diamantina-app`
3. Clic **Create repository**
4. Sube todos estos archivos arrastrándolos

### Paso 3 — Crear cuenta en Vercel
1. Ve a https://vercel.com
2. Clic **Sign up with GitHub**
3. Autoriza Vercel

### Paso 4 — Desplegar
1. En Vercel clic **Add New Project**
2. Selecciona el repositorio `diamantina-app`
3. Framework: **Vite**
4. Clic **Deploy** — espera 1 minuto
5. Te da una URL tipo: `https://diamantina-app.vercel.app`

### Paso 5 — Instalar en iPhone
1. Abre la URL en **Safari**
2. Toca el botón **Compartir** (cuadrado con flecha)
3. Toca **"Agregar a pantalla de inicio"**
4. Toca **Agregar**
5. ✅ Ya aparece como app en tu iPhone

### Paso 6 — Instalar en Android
1. Abre la URL en **Chrome**
2. Toca los **3 puntos** arriba
3. Toca **"Instalar app"** o **"Agregar a pantalla de inicio"**
4. ✅ Ya aparece como app en tu Android

---

## ✅ Una vez instalada
- Funciona **100% sin internet**
- Los datos se guardan en el dispositivo
- Se actualiza sola cuando hay internet
